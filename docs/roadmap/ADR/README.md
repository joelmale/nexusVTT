# Roadmap-Local ADRs

These ADRs belong to the historical 2026 A/B/C roadmap and keep their original
numbering for archival continuity.

They are intentionally separate from the canonical repository-wide ADR series
in `docs/adr/`. References to `ADR-0001` inside the archived roadmap usually
mean this roadmap-local series, especially:

- `0001-nexuscodex-boundary.md`

For new repository-wide architecture decisions, add records under `docs/adr/`
instead.
