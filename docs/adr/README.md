# Architecture Decision Records

This is the canonical repository-wide ADR series.

Use these ADRs for decisions that apply across Nexus VTT runtime boundaries,
architecture, persistence, deployment, or dependency direction.

The roadmap-local ADRs in `docs/roadmap/ADR/` are historical decisions from the
2026 A/B/C roadmap. They keep their original numbering but are not the canonical
repository-wide ADR sequence.
